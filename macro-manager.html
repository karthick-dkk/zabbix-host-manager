{$} Zabbix Macro Manager

Load a Zabbix template export

Drop a zbx_export_templates_*.json file here, or choose one. Everything runs locally in your browser; nothing is uploaded.

  • Macro names are locked. You can edit values, types and descriptions, but you can't add, delete or rename macros.
  • Bulk edit, find/replace and CSV/TSV import (paste straight from Excel).
  • Checks for broken macro mappings, wrong item value types and invalid values.
  • The export keeps the original file byte-for-byte, except for the fields you changed.

Import values (CSV / TSV / paste from Excel)

The header row must include a macro column plus at least one of value, description or type. An optional template column limits a row to one template. {$ES.HOST} and ES.HOST are both accepted. Rows naming a macro that doesn't exist are rejected, because names can't be created or changed.

Export

Download the current macros as CSV, edit them in Excel, then import them again on the left. Use one CSV per client as a reusable profile. Secret values are always left blank in CSV.
