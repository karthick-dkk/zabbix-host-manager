Connect to Zabbix

Loads hosts, host groups, linked templates and host macros through the Zabbix API. Nothing is written until you click Apply on the Review screen.

  • The token's user needs read-write permission on the client host groups to apply changes. Read-only works for review.
  • The page calls api_jsonrpc.php straight from your browser, and Zabbix allows this by default. If you open this file from disk and the browser blocks the request, serve it locally instead (python3 -m http.server).
  • The Zabbix URL and your Settings are stored in this browser only. The token is stored only if you choose to remember it above.

Pending changes

Duplicate interfaces: host renamer

These hosts share an interface (same address and port). For each set, the host with the discovered tag is disabled and renamed to <IP>-Temp. The host you keep gets hostname <IP>, and its visible name becomes its previous hostname. The discovered hosts are renamed first, in one batch, so the IP is free when the kept host takes it. Everything is staged for Review & apply.

Roles

Each role is a host group. The Elasticsearch Cluster by HTTP SISA template totals a client's hosts with group="{$GRP.CLIENT}" and group="<role group>", and only the four aggregated roles have items for this. The macro columns are read from the cluster host to show requested against allocated.
